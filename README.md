# Nazim Uddin Siam — Portfolio

A responsive, single-page personal portfolio for Nazim Uddin Siam.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — mobile menu + reveal animations

## Before publishing
1. Replace `your-email@example.com` in `index.html` with the real email.
2. Add real project cards as projects are completed.
3. Update GitHub/LinkedIn URLs if your public profile URLs differ.
4. Open `index.html` locally to preview.

## Publish
This is static HTML/CSS/JS, so it can be deployed on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any normal web host.
